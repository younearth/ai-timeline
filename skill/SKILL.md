# AI 타임라인 기록 지시

요청 시간, 완료 시간, Git이 감지한 변경 파일은 hook이 자동으로 기록한다.
너는 **hook이 알 수 없는 것**만 보고한다: 무엇을 했는지, 상태, 사용자가 처리할 일, 질의응답.

## 언제 쓰나

- 컨텍스트에 `[ai-timeline]` 안내가 있는 요청에서, 그 요청에 대한 **마지막 응답 끝에 한 번** 붙인다.
- 중간 진행 메시지나 도구 호출 사이에는 붙이지 않는다.
- 안내가 없으면(기록 대상 프로젝트가 아니면) 붙이지 않는다.

## 형식

응답 맨 끝에 언어 태그가 `ai-timeline`인 코드 블록 하나, 안에는 JSON 객체 하나만 둔다.

```ai-timeline
{
  "status": "완료",
  "title": "config 로더 exclude 처리",
  "summary": "config 로더에 exclude 처리 추가, 가장 긴 prefix 매칭으로 변경",
  "categories": ["config"],
  "files": ["core/config.js", "README.md"],
  "pendingForUser": [],
  "qna": [{ "q": "미등록 경로는 어떻게 되나?", "a": "unregistered가 ignore면 기록하지 않는다" }],
  "continues": null
}
```

| 필드 | 작성 기준 |
|---|---|
| `status` | `완료` — 요청을 끝냈다. `진행중` — 아직 남은 작업이 있고 내가 이어서 한다. `보류` — 내가 할 수 없거나 하면 안 되는 일이 남아 사용자가 처리해야 한다. 이 세 값 외에는 쓰지 않는다. |
| `title` | 요청을 한눈에 알아볼 수 있는 제목. 30자 안팎의 명사형 (예: "장바구니 합계 즉시 갱신", "데이터 공유 방식 질문"). 사용자 원문을 그대로 옮기지 말고 요약한다. 원문은 따로 기록되어 펼치기로 볼 수 있다. |
| `summary` | 무엇을 어떻게 바꿨는지 1~2문장. 코드를 바꾸지 않았으면 무엇을 조사·답변했는지 쓴다. |
| `categories` | 작업 분류, 해당하는 것 모두. `ui`(화면·스타일) `api`(서버·비즈니스 로직) `db`(쿼리·스키마·마이그레이션) `data`(데이터 파일·변환·수집) `infra`(배포·CI·실행 환경) `config`(설정·의존성) `docs`(문서) `test`(테스트) `qa`(코드 변경 없는 질문·조사·설명) `etc`(그 밖). 이 값 외에는 쓰지 않는다. |
| `files` | 이번 요청에서 **내가** 생성·수정·삭제한 파일. 프로젝트 루트 기준 상대 경로, 구분자는 `/`. 읽기만 한 파일은 넣지 않는다. 기억에 의존하지 말고 실제로 편집한 파일을 빠짐없이 적는다 — Git 감지 결과와 비교되어 불일치는 빨간색으로 표시된다. |
| `pendingForUser` | `보류`일 때 사용자가 직접 해야 할 일 (예: "운영 DB에 코드 테이블 INSERT", "API 키 발급"). 없으면 `[]`. |
| `qna` | 이번 요청에서 오간 질문과 답, 또는 나중에 "왜 이렇게 했지?"를 설명해 줄 설계 판단. 한 항목은 짧게. 없으면 `[]`. |
| `continues` | 직전 작업을 이어서 하는 요청이면(예: "계속해", 직전 결과 수정) 안내에 나온 직전 작업 id. 아니면 `null`. |

## 지킬 것

- JSON은 표준 문법으로 쓴다 (주석·후행 쉼표 금지, 문자열은 큰따옴표).
- 경로는 `files`뿐 아니라 `summary`·`qna`·`pendingForUser`에서도 **프로젝트 루트 기준 상대 경로**로만 쓴다. 절대 경로(`/Users/...`, `/home/...`, `C:\Users\...`)는 사용자명이 드러나므로 쓰지 않는다. 프로젝트 밖 경로가 꼭 필요하면 `~/...`로 쓴다. (hook이 기록 전에 한 번 더 변환하지만, 처음부터 상대 경로로 쓴다.)
- 키·토큰·비밀번호, 이메일은 쓰지 않는다.
- 블록은 응답에 하나만. 여러 개면 마지막 것만 기록된다.
- 블록 앞에 평소대로 사용자에게 할 말을 먼저 쓴다. 블록은 기록용 부록이다.
