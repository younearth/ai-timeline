## 기기명(`device`) 형식 검사
- **배경**: `device`는 기기별 `config.json`에 직접 적는 값이고, 데이터 파일명(`YYYY-MM-DD.<device>.jsonl`)과 작업 id에 그대로 들어간다. 지금 `core/config.js`는 값이 있는지만 확인한다.
- **문제**: `/`·공백·`:` 같은 문자가 들어가면 파일 경로가 깨지거나 Windows에서 파일을 만들 수 없다.
- **할 일**
  - [ ] `core/config.js`: `device`가 `^[a-z0-9][a-z0-9-]{0,31}$`이 아니면 오류 (hook은 오류 로그만 남기고 기록하지 않음, Claude Code 작업은 막지 않음)
  - [ ] `scripts/install.js`: 설치 시 같은 규칙으로 미리 검사해 바로 알려 주기
  - [ ] (선택) `build.js`: 같은 기기명으로 시간이 겹치는 서로 다른 세션 기록이 있으면 "기기명 중복 의심" 경고 — 두 기기에 같은 이름을 쓴 실수는 기기끼리 알 수 없어 기록 시점에 막을 수 없음
